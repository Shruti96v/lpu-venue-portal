## Brand & Style

This design system embodies the polished precision of haute cuisine orchestrated by an invisible, proactive digital brigade. Designed for owners, general managers, and floor staff in high-caliber dining establishments, the aesthetic merges the tactile warmth of heritage hospitality with the razor-sharp telemetry of autonomous AI agents. 

The aesthetic is **Modern Epicurean SaaS**: grounded luxury built on creamy warm surfaces, architectural botanical greens, and calibrated culinary accents. It replaces the sterile, hyper-technical visual tropes of modern SaaS with the reassuring gravity of fine dining service—deliberate, tranquil, and hyper-competent under pressure. High-density operations (live floor plans, ticket queues, inventory forecasting, multi-agent dispatch) remain legible and stress-free through spacious editorial hierarchy, organic containment lines, and whisper-quiet status states.

## Colors

The palette draws inspiration from classic brass-accented brasseries, botanical conservatory glasshouses, and freshly plucked saffron threads.

- **Primary (`#183B2B`)**: Deep Conservatory Forest Green. Anchors navigation rails, primary action triggers, and primary metrics. It conveys permanence, calm competence, and institutional authority.
- **Secondary (`#E07A5F`)**: Warm Terracotta Saffron. Reserved for high-value interventions: autonomous AI recommendations, urgent table calls, live modifier alerts, and pending confirmations.
- **Tertiary (`#4C8B64`)**: Soft Sage Green. Applied to structural badges, agent-active status indicators, and operational vitality meters.
- **Neutral (`#1C1F1D`)**: Charcoal Espresso. High-contrast, warm dark neutral replacing cold jet black to preserve optical softness across lengthy kitchen or floor shifts.

### Canvas & Surface Architecture
- **Base Canvas**: `#FDFBF7` (Warm Cream).
- **Secondary Canvas / Card Surfaces**: `#F7F4EE` (Pressed Linen).
- **Structural Outlines & Separators**: `#E3ECE6` (Sage Mist) and `#EAE4D9` (Warm Bone).

### Agent and Operational Status Accents
- **Available / Clear**: Tinted `#4C8B64` on `#EBF3EE`.
- **Occupied / Seated**: Tinted `#2A5A44` on `#E3ECE6`.
- **Reserved**: Tinted `#6B5E4F` on `#F2EFE9`.
- **Preparing / In-Flight**: Tinted `#C97A2B` on `#FAF1E6`.
- **Ready / Expedite**: Tinted `#E07A5F` on `#FAECE8`.
- **AI Agent Live Pulse**: Tinted `#183B2B` with a diffuse radial aura of `#E07A5F` (12% opacity).

## Typography

The type system creates tension between an intellectual, bespoke European hospitality identity (**Newsreader**) and crisp, high-legibility digital interface mechanics (**Plus Jakarta Sans**).

- **Editorial Touchpoints**: Use Newsreader exclusively for major section banners, system greeting moments, revenue and analytics summaries, and table status card titles. Its italic style is reserved for AI agent thoughts, live concierge logs, and guest sentiment quotes.
- **Operational Clarity**: Plus Jakarta Sans handles telemetry, agent action grids, floor matrix numbers, ticket lists, and modal controls. Its high x-height and generous open counters maintain legibility on handheld POS tablets and wall-mounted kitchen monitors under intense ambient lighting.
- **Numerical Tabulation**: All floor status counters, covers, pacing timelines, and currency fields must use tabular numbers (`font-variant-numeric: tabular-nums`).

## Layout & Spacing

The layout model uses a responsive fluid grid structured for dense information architecture:
- **Desktop (1200px+)**: 12-column layout with 24px gutters and 40px outer canvas margins. Features a persistent 260px slim navigation sidebar for agent overview, dining room floor zones, and station switching. Multi-agent streams collapse into an expandable 360px right-hand observation drawer.
- **Tablet (768px – 1199px)**: 8-column fluid layout with 20px gutters and 24px margins. Navigation shifts to a collapsible off-canvas rail; cards for tables and agents default to 2-up and 4-up grids.
- **Mobile (Below 768px)**: 4-column layout with 16px gutters and 16px margins. Bottom action docking replaces side drawers. Operational tickets stack vertically with touch targets expanded to a minimum of 48px height.

Spacing follows an authentic baseline rhythm where internal component padding stays compact (`space-sm` to `space-md`) to maximize vertical real estate for live order tracking, while outer structural gaps use generous boundaries (`space-lg` to `space-xl`) to prevent sensory overload during dinner rush.

## Elevation & Depth

Visual depth is achieved through **tonal stratification and atmospheric micro-shadows** rather than blunt drop-shadows.

1. **Surface Tiers**:
   - `Tier 0 (Canvas)`: `#FDFBF7` – Ambient room canvas.
   - `Tier 1 (Panels & Cards)`: `#FFFFFF` or `#F7F4EE` bounded by a 1px delicate outline in `#E3ECE6`.
   - `Tier 2 (Popovers, Flyouts, Active Modifiers)`: Pure `#FFFFFF` layered over Tier 1.
2. **Micro-Shadow Profile**:
   - Low: `0 1px 3px rgba(24, 59, 43, 0.04), 0 1px 2px rgba(24, 59, 43, 0.02)`
   - Floating Modals & Agent Tooltips: `0 8px 24px -4px rgba(24, 59, 43, 0.08), 0 2px 6px -1px rgba(24, 59, 43, 0.03)`
3. **AI Agent Subtle Bloom**:
   - For autonomous actions taking place in real time, agent avatars and suggestion pill containers emit a gentle breathing glow: `box-shadow: 0 0 0 1px rgba(76, 139, 100, 0.3), 0 0 16px 2px rgba(224, 122, 95, 0.12)`.

## Shapes

The interface embraces a refined, architectural curvature (`roundedness: 2` / 0.5rem base radius).
- **Core Elements**: Standard cards, inputs, dropdowns, and table status blocks use `rounded-md` (8px / 0.5rem).
- **Large Structural Containers**: Dining room grid frames, agent orchestrator drawers, and modal sheets utilize `rounded-lg` (16px / 1rem).
- **Interactive Badges & Status Chips**: Use continuous pill geometry (`rounded-full`) to maintain distinct visual separation from structural cards and data cells.

## Components

### Buttons
- **Primary**: Background `#183B2B`, text `#FFFFFF`, 0.5rem radius, height 40px (desktop) / 48px (mobile). Hover shifts to deep pine `#204B38` with subtle transform lift (`translateY(-0.5px)`).
- **Secondary / Agent Assist**: Background `#F7F4EE`, 1px border `#E3ECE6`, text `#183B2B`. Hover triggers background `#EBF3EE`.
- **Urgent / Expedite Action**: Background `#E07A5F`, text `#FFFFFF`. Hover deepens to `#D36B50`.

### Status Badges & Chips
- Compact pill design with uppercase tracking (`label-sm`).
- **Available**: Surface `#EBF3EE`, Border `#C5DDCF`, Text `#183B2B`.
- **Occupied**: Surface `#E3ECE6`, Border `#A9C5B4`, Text `#183B2B`.
- **Reserved**: Surface `#F4EFE6`, Border `#DCD2C1`, Text `#5E5343`.
- **Preparing**: Surface `#FDF4EB`, Border `#F3D4BA`, Text `#B85D1B`.
- **Ready**: Surface `#FBEAE6`, Border `#F4C5BA`, Text `#B9492E`.

### AI Agent Badges & Indicator Tiles
- **Agent Presence**: Rounded container with an avatar icon, agent identity label (e.g., *Sommelier Agent*, *Host Dispatch*, *Pacing Engine*), and a 6px status LED.
- **Active State**: The LED animates between `#4C8B64` and `#E07A5F` through a gentle CSS breathe transition (2.4s period), communicating ongoing analysis without distraction.
- **Agent Recommendation Cards**: Contained within `#FFFFFF` cards framed by a 1px border `#E3ECE6` and a left-accent stroke (3px) in `#E07A5F`. Includes prompt decision chips (*Approve Re-seat*, *Fire Course 2*, *Adjust Inventory*).

### Table Cards (Floor Plan Matrix)
- Card base: `#FFFFFF` or `#F7F4EE` based on status.
- Displays table number in Newsreader 20px, guest headcount, elapsed turn-time, assigned waiter, and current AI pacing alert.
- Quick-action buttons revealed on hover or touch focus.

### Input Fields & Controls
- Base: Background `#FFFFFF`, 1px border `#E3ECE6`, text `#1C1F1D`, placeholder `#8F9691`.
- Focus State: Border color `#183B2B` with an ambient ring: `0 0 0 3px rgba(24, 59, 43, 0.08)`.
- Checkboxes & Radios: Forest green `#183B2B` fill with smooth spring transitions.
